# Demo checklist

## Design checkpoint (available now)

- [x] Follow README to start Vite; backend uses existing local secrets and database setup.
- [x] Open the three `/design/*` samples; sample content is visibly labeled.
- [x] Inspect desktop/mobile and light/dark screenshots.
- [x] Try theme, form validation, search/filter, sample send, dialog and mobile navigation.
- [x] Build, unit/component tests, design browser tests and anonymous live boundaries.
- [ ] Product Owner approves design and baseline is recorded in roadmapFE.md.

## Full portfolio demo (remaining work)

- [ ] Configure two authorized test accounts through secure environment input.
- [ ] Register → verify → login; refresh/reload recovery; logout and session revoke.
- [ ] Search → friend request → second-account accept; block/unblock permissions.
- [ ] Private send/receive realtime between two browsers; reconnect and missed-event recovery.
- [ ] Reply/edit/recall/reaction/search/history; real delivered/seen; request inbox.
- [ ] Create/invite/join group, role boundaries, pins, ownership transfer/leave.
- [ ] Authorized file upload/preview/download with invalid-file/error cases and URL cleanup.
- [ ] Notifications, mute, profile/privacy/email/username/password/session settings.
- [ ] Reports and isolated suspended-account appeal identity.
- [ ] System Admin dashboard, case claim/evidence/moderation, appeals/audit/retention previews and holds.
- [ ] Real mobile keyboard, browser compatibility, accessibility and performance/regression audits.
- [ ] Final API/event coverage audit and PASS/FAIL/NOT TESTED/BLOCKED report.
- [ ] Propose PORTFOLIO_READY only after evidence satisfies the full Definition of Done.

Do not run destructive moderation/retention tests against existing data without explicit authorization. Design fixtures never count as real demo data or integration success.
